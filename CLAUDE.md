# Learning Design Aotearoa (LDA) — website brief

This folder holds the approved structure and copy for the LDA website. Build pages from the files in `content/`. Do not invent or rewrite approved copy; if something is missing or unclear, ask Shea.

## The business

Learning Design Aotearoa is a New Zealand business serving the education sector (schools, kura, early learning, education organisations), with possible corporate work later. It is a branded house: everything sits under the LDA parent name.

- **New curriculum** — tools and support for the new NZ Curriculum (NZC), led by a curriculum mapping / unit planning / lesson planning tool. This is a product, not a service, and is the site's main hook.
- **LDA Creative** — what we make: brand and documents, book design, web additions, concrete school stencils.
- **LDA Consulting** — work with organisations: strategic planning, learning design, leadership structures.
- **LDA Leadership** — NOT launching yet. Keep it out of the navigation. A quiet "Coming soon: LDA Leadership" line in the footer or About page is fine. Draft copy is parked in `content/_later-leadership.md`.

## Writing rules (apply to any new or placeholder text)

- NZ English spelling: organisation, programme, colour, licence (noun), license (verb).
- Never use the word "solutions". Use concrete nouns schools recognise.
- Lead with the client's benefit, not a description of LDA.
- The core differentiator is that LDA is built by people who work inside education. Use it, but don't overdo it.
- Plain, warm, professional. Written for busy principals, SLT, boards and HODs, often reading on a phone.
- LDA does NOT build full websites — only additions to existing school websites. Never imply otherwise.
- Square-bracket text like `[Example: …]` or `[TOOL NAME]` is a placeholder. Leave it visible and flag it; don't fill it with made-up content.

## Cultural constraint (non-negotiable)

The name "Aotearoa", te reo Māori and Māori visual motifs (koru, niho taniwha, etc.) carry cultural obligations. Do not add te reo phrases, Māori motifs or patterns to the design or copy unless Shea confirms they have been through appropriate cultural guidance. Using the business name as given is fine.

## Brand

- Hero layout reference: `assets/hero-layout-reference.png` — logo centred, one text block top-left (Creative), one bottom-right (Consulting), wide letter-spacing. Copy is in `content/home.md`.

## Page template

Every section page follows the same pattern, so build it as a reusable template:

1. Section title + benefit-led headline
2. Intro paragraph
3. Service blocks: heading, one-line tagline, paragraph, "Ideal for:" line, optional example placeholder
4. "How we work"
5. Call to action + contact button
